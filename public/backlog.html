Feature Ideas
  • Weekly meal planner Drag recipes onto a 7-day calendar view.
  • Auto-generated grocery list Build a shopping list from a week's planned meals.
  • Print-friendly recipe view A clean, ink-friendly layout for printing a single recipe.
  • Installable app (PWA) Add to home screen and use offline.
  • Photo upload for My Own recipes Attach your own photo instead of a stock image.
  • Import a recipe from a URL Paste a link and auto-fill title/ingredients/steps.
  • Serving-size scaler Adjust ingredient quantities for more/fewer servings.
  • Ingredient substitution suggestions Quick swaps for common allergies or missing items.
  • Leftover / batch-cook tracker Mark a recipe as "cooked, N portions left".
  • Weekly nutrition summary Totals of calories/protein for liked or planned recipes.
  • Daily protein/calorie goal tracker Set a target and see progress as you plan meals.
  • "Surprise me" random recipe picker One tap to get a random not-disliked, not-hidden recipe.
  • Shared profiles (you + spouse) Separate like/dislike state per person on shared recipes.
  • Freeform recipe notes/comments Jot your own tweaks or comments on any recipe.
  • Tag-based smart filters Quick filter chips like "quick", "meal-prep", "one-pan".
  • Cooking mode Full-screen step-by-step view, screen stays awake.
  • Built-in step timers Start a timer directly from a cooking step.
  • Seasonal recipe highlighting Surface recipes that fit the current season.
  • Export/share a recipe as image or PDF Send a recipe to someone without the app.
  • Recently viewed history Quick access to the last few recipes you opened.
